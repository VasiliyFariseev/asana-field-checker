# Field Checker — поиск задач с незаполненными FD-полями

> 🔒 **Репозиторий должен быть приватным.** В `config.py` лежит рабочий токен Asana. Не выкладывайте архив в общий доступ — только личным сообщением.

Задачи, идущие в билд, обязаны иметь заполненные поля **«FD: Version»** и **«FD Milestone»** — но люди заполняют их не всегда, и такие задачи теряются. Инструмент проходит по проектам Asana и раскладывает задачи по трём корзинам:

- **⚠ заполнено только одно** — самые коварные: наполовину оформленная задача выглядит нормальной;
- **✗ оба поля пустые**;
- **✓ оба заполнены**.

Работает на macOS и Windows, нужен только Python 3 (с python.org).

---

## Скачать

Один файл — `Field-Checker.zip` со страницы [Releases](../../releases/latest) (блок Assets). Распакуйте в отдельную папку и запустите:

- macOS — двойной клик по `START_MAC.command` (первый раз: правый клик → «Открыть» → «Открыть»);
- Windows — двойной клик по `START_WINDOWS.bat`.

## Как пользоваться

1. В поле проектов уже стоит Expedition Team QA; можно вписать несколько GID через запятую (GID — число из ссылки `.../project/<число>/...`). Вставка работает и правым кликом (меню «Вставить»), и Cmd/Ctrl+V в любой раскладке.
2. **«Проверить»** — задачи прочитаются из Asana (по большим проектам виден прогресс). Галочка «с сабтасками» (включена по умолчанию) спускается и в сабтаски — любой вложенности; в таблице они с префиксом «↳», секция наследуется от верхней задачи. Сабтаски закрытых задач тоже проверяются — среди них могут прятаться незакрытые.
3. Выпадашка «Показать» переключает корзины; строки подкрашены: зелёные — всё заполнено, жёлтые — только одно поле, красные — пусто. В таблице видно секцию, исполнителя и значения обоих полей.
4. Двойной клик открывает задачу в Asana. Правый клик по строке показывает **все** кастом-поля задачи, как их отдаёт API (и копирует список в буфер) — полезно, когда кажется, что поле заполнено, а инструмент его не видит. **«Скопировать список»** кладёт текущую корзину в буфер со ссылками и исполнителями — готовый пост в чат «коллеги, заполните поля».

Завершённые задачи по умолчанию пропускаются — галочка «включая завершённые» возвращает их. Инструмент только читает: ничего в Asana не меняет.

## Из терминала

```bash
python3 field_checker.py                           # проект по умолчанию, корзина «только одно»
python3 field_checker.py --projects "gid1,gid2"    # несколько проектов
python3 field_checker.py --show none               # partial | none | both | all
python3 field_checker.py --completed               # включая завершённые
python3 field_checker.py --no-subtasks             # не спускаться в сабтаски
```

## Для тех, кто правит код

- `field_checker_ui.py` — окно; `field_checker.py` — логика и CLI; `config.py` — токен, проект по умолчанию, **имена проверяемых полей** (`FIELD_A`, `FIELD_B` — поменяйте, если поля называются иначе) и сетевая сессия с таймаутами.
- Поля ищутся по имени без учёта регистра и по вхождению: «FD: Version» найдёт и «FD:Version».
- Тесты (без сети, на заглушках): `xvfb-run -a python3 tests/smoke_checker.py` — гоняются в CI на каждый push.
- Релиз собирается сам: `git tag v1.2 && git push origin v1.2` → GitHub Actions собирает `Field-Checker.zip` и создаёт релиз.
- Токен можно переопределить переменной окружения `ASANA_TOKEN`.
